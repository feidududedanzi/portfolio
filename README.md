# 陈路阳作品集 · GitHub Pages

这是适配 GitHub Pages 的静态发布包。保留作品集 /lens/ 新版及所有素材。

GitHub Actions 自动解压 website.zip，按当前仓库名称适配资源和路由前缀，然后部署。个人站点仓库（用户名.github.io）和项目仓库均可。

部署：将本目录内容提交到 GitHub 仓库 main 分支，进入 Settings → Pages，把 Source 设为 GitHub Actions，然后运行 Publish portfolio to GitHub Pages。以部署任务实际返回的 URL 为准。

网站包含用户此前明确允许公开的手机号、邮箱、简历和项目素材。GitHub 公共仓库中的文件也可以被下载。
